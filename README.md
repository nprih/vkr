На главной странице отображаются фотографии, которые загрузили пользователи.
Нажмите на любую карточку, чтобы открыть изображение в полном размере.

Вход и регистрация: Формы на страницах «Войти» и «Регистрация» позволяют создать 
новый аккаунт или войти в существующий. 

## Для тестирования уже создан администратор и простой пользователь:
## admin / admin123
## user / user123
## Также загружено несколько картинок от каждого пользователя (admin, user)

Панель администратора: Эта страница видна только после входа под учетной записью с ролью «админ». 
Здесь вы можете управлять всеми пользователями (например, удалить любого, кроме администратора) и модерировать 
все загруженные фото (просматривать и удалять любые снимки).

Личный кабинет: Страница «Профиль» — это рабочее пространство пользователя. Здесь можно загружать 
новые фото. Здесь же можно удалить свои работы.

Перезапуск сервера не приводит к отмене авторизации пользователей. 
Время жизни авторизации 1 час. (можно изменить в cmd/main.go **const sessionLifetime**)

# На данный момент Реализовано:

## 1. Сервер запускается командой из консоли go run cmd/main.go
## 2. Используется фреймворк GIN
## 3. В качестве БД используется sqlite (файл с БД volumes/photo_bank)
## 4. Регистрация, авторизация пользователей, а также выход из учетной записи
## 5. Необходимые маршруты находятся под AuthMiddleware
## 6. Отображение пунктов меню поставлено в зависимость от того какой пользователь пришел
## 7. Загрузка картинок пользователей в профиле (/profile)
## 8. На главную выводятся все загруженные картинки пользователей на основе данных из БД в обратном порядке по дате добавления
## 9. В профиле пользователя также выводятся все загруженные картинки данного пользователя на основе данных из БД в обратном порядке по дате добавления
## 10. После успешного добавления картинки в профиле обновляются списки без перезагрузки страницы
## 11. Обновление картинок в профиле после загрузки новой картинки без перезагрузки страницы
## 12. Удаление картинок с обновлением списков без перезагрузки страниц
